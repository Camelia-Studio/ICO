# ICO

Galerie d'illustrations de l'association **Camélia Studio**.

Il s'agit d'un outil de galeries d'illustrations simple et léger en PHP, que vous pouvez réutiliser et adapter pour vos besoins.

- Pour la liste des fonctionnalité [voir la page du wiki dédiée](https://git.crystalyx.net/camelia-studio/ICO/wiki/Fonctionnalit%C3%A9s)
- Pour l'installation et la mise à jour [voir la page du wiki dédiée](https://git.crystalyx.net/camelia-studio/ICO/wiki/Installation-%26-mise-%C3%A0-jour)
