# ICO

Galerie d'illustrations de l'association **Camélia Studio**.

Il s'agit d'un outil de galeries d'illustrations simple et léger en PHP, que vous pouvez réutiliser pour vos besoins.

### Fonctionnalités actuelles
- Partie publique avec une page d'accueil décrivant le site site. Les cinq dernières images téléversées s'affichent à tour de rôle en fond.
![image](https://concepts.esenjin.xyz/cyla/v2/file/315088.png)
- Affichage des albums et sous-albums.
![image](https://concepts.esenjin.xyz/cyla/v2/file/9FAAF3.png)
- Montre les images d'un album dans une galerie de type *Mansory*.
![image](https://concepts.esenjin.xyz/cyla/v2/file/3D30C4.png)
- Possibilité d'afficher en grand une illustration en cliquant dessus, des options de partage sont disponibles.
![image](https://concepts.esenjin.xyz/cyla/v2/file/B2D3D0.png)
- Partie administration qui permet de gérer le site.
![image](https://concepts.esenjin.xyz/cyla/v2/file/36E4D7.png)
- Connexion avec un identifiant et un mot de passe.
- Possibilité de changer son mot de passe.
- Permet de voir l'arborescence des albums, de les éditer, d'en ajouter ou d'en supprimer.
![image](https://concepts.esenjin.xyz/cyla/v2/file/3A0DFC.png)
![image](https://concepts.esenjin.xyz/cyla/v2/file/A6A205.png)

![image](https://concepts.esenjin.xyz/cyla/v2/file/7A5C3C.png)

## Installation
- Télécharger l'archive `.rar` de la branche `main`.
- Extraire l'archive dans un dossier dédié pour.
- Téléverser les fichiers (ainsi que le dossier `liste_albums` !) sur votre serveur.
- Accéder à la page `init-db-php.php`, par exemple `https://ma-galerie.org/init-db-php.php`. Cela va créer la base de données `database.sqlite`, avec un utilisateur « admin », ayant par défaut le mot de passe « admin ». Vous devriez avoir un message de confirmation si cela s'est bien passé.
- Supprimer le fichier `init-db-php.php` de votre serveur !
- Accéder à l'interface d'administration et changer votre mot de passe !
- Bravo ! Vous pouvez désormais utiliser ICO.

## Mettre à jour
- Télécharger l'archive `.rar` de la branche `main`.
- Extraire l'archive dans un dossier dédié pour.
- Supprimer le fichier `init-db-php.php`.
- Téléverser les fichiers sur votre serveur et tout écraser.
- Super ! ICO est maintenant à jour.
